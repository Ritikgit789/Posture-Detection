# Posture-Detection
Developed an AI based web application "Home Workout" to detect gymnasium postures using Mediapipe's Blazepose model & openCV.
-- ** Posture detection using landmarks involves identifying key points on the human body, such as joints (shoulders, elbows, knees), facial features (eyes, nose), and extremities (wrists, ankles). These landmarks are tracked using computer vision models like MediaPipe and BlazePose, which estimate their positions in real-time. The detection process relies on coordinate systems (x, y, z) to map body movements and assess posture. Key insights include recognizing symmetry, alignment, and deviations from standard poses. Applications range from fitness tracking and ergonomic assessments to rehabilitation and gaming. Landmark-based posture detection enhances accuracy, efficiency, and adaptability in human body analysis.
